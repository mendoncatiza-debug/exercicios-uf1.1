# Exercício Prático: As Aldeias Históricas 🏰

Hoje ligámos as páginas do nosso portefólio com um menu de navegação funcional, explorámos hiperligações externas e de e-mail, e organizámos a informação com listas e tabelas acessíveis. Agora é a vossa vez: vão expandir a página da vossa cidade e construir de raiz uma página informativa sobre as Aldeias Históricas de Portugal.

O vosso objetivo é consolidar a utilização do elemento `<a>` (com links internos, externos e de correio), listas ordenadas e não ordenadas (`<ol>`, `<ul>`, `<li>`), e tabelas de dados estruturadas e acessíveis (`<table>`, `<caption>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`).

Os ficheiros de que precisam estão na pasta [`ex-005/`](./ex-005/): `aldeias-historicas.txt`.

### Missão 1: A Minha Cidade, Versão 5

1. Criem a pasta `sessao-05` dentro de `exercicios-uf1.1` e copiem para lá **todo o conteúdo** da pasta `sessao-04` (incluindo a pasta `imagens`).
2. Abram o ficheiro `cidade.html` e façam as seguintes melhorias:
   - No `<header>`, dentro de um `<nav>`, criem um menu com uma lista não ordenada (`<ul>`) de links de âncora para as secções da página (`#onde-fica`, `#historia`, `#visitar`, `#monumentos`, `#ditado`).
   - Adicionem o atributo `id` correspondente a cada `<section>` do `<main>`.
   - Na secção "Onde fica", adicionem um link externo para o portal oficial do município ou de turismo local com `target="_blank"` e `rel="noreferrer noopener"`.
   - Na secção "O que visitar", transformem os pontos de interesse numa lista não ordenada (`<ul>`), destacando cada monumento com `<strong>`.
   - Criem uma nova secção com o título "Principais monumentos" contendo uma tabela semântica (`<table>`) com `<caption>`, `<thead>`, `<tbody>`, cabeçalhos `<th>` com atributo `scope="col"` e pelo menos 3 linhas com dados de monumentos da vossa terra (Monumento, Construção/Século, Estilo, Classificação).
3. Validem no [validador do W3C](https://validator.w3.org/#validate_by_input).
4. Façam o ciclo de trabalho no Git:
   - `git add .`
   - `git commit -m "Cidade com navegacao interna listas e tabela"`
   - `git push`

### Missão 2: As Aldeias Históricas de Portugal

Vão criar uma página completa sobre um dos roteiros culturais e históricos mais bonitos do país, partindo de um texto em bruto.

1. Copiem para a vossa pasta `sessao-05` o ficheiro [`aldeias-historicas.txt`](./ex-005/aldeias-historicas.txt).
2. Criem o ficheiro `aldeias-historicas.html` com a estrutura base completa (`<!doctype html>`, `<html lang="pt-PT">`, `head`, `body`). O título do separador deve ser "Roteiro das Aldeias Históricas de Portugal".
3. Estruturem o conteúdo com os elementos semânticos aprendidos:
   - `<header>` com o título principal (`<h1>`), o parágrafo de introdução e um `<nav>` com uma lista (`<ul>`) de links de âncora para as quatro secções (`#roteiro`, `#mochila`, `#guia`, `#contactos`).
   - `<main>` com quatro secções identificadas por `id`:
     - Secção "Roteiro sugerido (3 dias)" com uma lista ordenada (`<ol>`) descrevendo as atividades de cada dia.
     - Secção "O que levar na mochila" com uma lista não ordenada (`<ul>`) com os itens essenciais para a caminhada.
     - Secção "Guia das aldeias em destaque" com uma tabela completa (`<table>`): deve ter uma legenda descritiva (`<caption>`), cabeçalho (`<thead>`) com `<th> scope="col"` e corpo (`<tbody>`) com as 5 aldeias do ficheiro de texto, usando `<th> scope="row"` para o nome de cada aldeia e `<td>` para os dados restantes.
     - Secção "Contactos e apoio ao visitante" com uma lista de contactos contendo um link de correio com `mailto:` e um link externo para o portal oficial abrindo num novo separador (`target="_blank"` e `rel="noreferrer noopener"`).
   - `<footer>` com os direitos de autor (`&copy; 2026 Rede das Aldeias Históricas de Portugal`).
4. Validem no [validador do W3C](https://validator.w3.org/#validate_by_input) até não existirem erros.
5. Façam o ciclo de trabalho no Git:
   - `git add .`
   - `git commit -m "Pagina das Aldeias Historicas com listas e tabela"`
   - `git push`

**Critérios de sucesso:**

- [ ] A pasta `sessao-05` tem `cidade.html` atualizado e `aldeias-historicas.html` criado.
- [ ] O menu de navegação em ambas as páginas é composto por `<nav><ul><li><a href="...">...</a></li></ul></nav>`.
- [ ] Os links de âncora funcionam e saltam suavemente para a secção correta.
- [ ] Os links externos têm `target="_blank"` acompanhado de `rel="noreferrer noopener"`.
- [ ] O link de e-mail usa o protocolo `mailto:`.
- [ ] O itinerário diário usa uma lista numerada (`<ol>`).
- [ ] As recomendações e contactos usam listas com marcas (`<ul>`).
- [ ] A tabela inclui `<caption>`, `<thead>`, `<tbody>`, e células `<th>` com `scope="col"` e `scope="row"`.
- [ ] O validador do W3C não apresenta erros de sintaxe ou aninhamento.
- [ ] O repositório no GitHub reflete todos os novos commits.
