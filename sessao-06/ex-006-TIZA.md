Missão 3: O Relatório
Respondam às seguintes questões por palavras vossas:
A diferença entre name e id: Qual é o papel do atributo id e do atributo name num campo de formulário? O que acontece aos dados introduzidos pelo utilizador quando um campo não tem o atributo name? Resposta: 

id Serve para identificar de forma única o elemento na página.

 name Serve para identificar o campo quando o formulário é submetido para o servidor.

Rádios vs Checkboxes: Em que circunstâncias devemos utilizar botões de rádio (type="radio") e em que casos devemos optar por caixas de verificação (type="checkbox")? Qual é a regra técnica para que vários botões de rádio pertençam ao mesmo grupo de escolha exclusiva? Resposta:

Radio  Devem ser utilizados quando o utilizador precisa de escolher apenas uma única opção

  Checkboxes      
  é quando o utilizador tem uma lista e pode escolher mais que uma opção
